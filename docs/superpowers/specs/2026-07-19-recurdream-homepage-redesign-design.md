# 递归梦境 API 首页视觉重设计

## 目标

为递归梦境 API 设计一版兼顾新访客转化与已有用户快速进入控制台的首页。页面需要有明确的科技感和成熟企业气质，同时与现有 Vue 3、Tailwind、青绿品牌色和后台界面保持一致。

本轮先交付独立高保真预览和桌面端效果图，不直接替换生产首页。首页限定为单屏构图，默认使用深色主题，并保留浅色主题切换。

## 视觉方向

采用「企业级 API 控制平面」方向：

- 以雾白、纯白和深墨色建立稳重的页面骨架。
- 从现有 Logo 提取青绿与电蓝作为强调色，避免大面积单色铺陈。
- 减少渐变光斑、玻璃卡片和过度圆角，使用清晰分区、细边框和克制阴影。
- 科技感由真实的 API 路由、端点、延迟和运行状态信息表达，不使用纯装饰赛博元素。
- 品牌 Logo 与「递归梦境API」必须在首屏成为主要视觉信号。
- 当前只展示已经提供服务的 GPT 与 Claude，不出现 Gemini、Grok 或“40+ 模型”等未上线能力。

## 单屏结构

### 顶部导航

- 左侧为现有 Logo 和品牌名「递归梦境API」。
- 中部为「产品能力」「支持模型」「服务状态」「接入文档」。
- 右侧为语言/主题图标、「登录」次按钮和「开始使用」主按钮。
- 导航高度 72px，保持固定但不过度悬浮。

### 主视觉

- 使用全宽、非卡片式构图，不采用传统左右分栏的“文案 + 截图卡片”。
- H1 使用品牌名「递归梦境API」，价值主张放在支持文案中。
- 主文案强调一个 API Key 接入 GPT 与 Claude，以及稳定路由、透明计费与用量控制。
- 主操作为「开始使用」，次操作为「查看接入文档」。
- 背景集成低对比度双通道路由扫描场：纵向扫描束依次识别请求入口、智能网关、GPT 与 Claude 节点，节点被识别时显示扩散响应，并展示 200 响应与延迟数据。
- 主视觉、运行状态和模型能力必须全部容纳在一个桌面视口内，页面不依赖向下滚动传达核心信息。

### 底部状态带

- 以一条紧凑状态带展示动态稳定运行时长、可用性、平均响应时间与当前支持模型，状态带固定在单屏主视觉底部。
- 稳定运行时长以 `Wei-Shaw/sub2api` GitHub 仓库的公开创建时间 `2025-12-18T02:26:18Z` 为统计起点，按天、时、分、秒每秒更新。
- 模型区域只使用品牌名称和现有图标体系展示 Claude 与 GPT，不手绘品牌图标。
- 明确统一端点和 OpenAI/Anthropic 兼容能力。

### 微型页尾

- 状态带下方只保留版权和兼容协议说明，不增加新的内容区块。
- 登录、控制台和接入文档入口都在主视觉内完成，不设置重复 CTA。

## 视觉系统

- 页面背景：`#F7F9FA`；主要表面：`#FFFFFF`；深色区域：`#0C1518`。
- 正文：`#162326`；次级文字：`#5E6D70`；边框：`#DDE5E6`。
- 品牌青绿：`#18C7A2`；品牌电蓝：`#2F7DFF`；状态绿：`#16A36A`。
- 正文字体优先使用系统中文无衬线字体；数字、端点和延迟使用等宽字体。
- 圆角控制在 4px 至 8px；主按钮 6px；状态胶囊仅用于真正的状态信息。
- 图标统一为 1.75px 线性风格，交互区域至少 44px。
- 动画只用于路由脉冲、状态变化和按钮反馈，并尊重 `prefers-reduced-motion`。
- 深色主题使用接近黑绿的 `#071114` 作为背景，文字、边框和路由线分别校准对比度，不采用浅色主题的简单反色。
- 深色主题为默认主题；扫描束、节点识别波纹、双线路请求粒子、状态阶段循环和动态运行时长均表达实时业务状态，不增加无语义装饰动画。
- 扫描状态按「扫描入口、识别网关、Claude 就绪、GPT 就绪、路由成功」循环；首屏文案按层级依次进入，关键词使用低频流光强调。

## 响应式规则

- 桌面基准为 1440 x 900px，内容最大宽度约 1200px，完整首页高度等于视口高度。
- 首屏在 1280px 以上保持完整路由场景，在平板收缩节点数量，在手机端转为纵向端点流。
- 手机基准为 390 x 844px；导航折叠为品牌和菜单，路由场景缩小，状态带改为两列，主操作保持可见。
- 所有正文至少 16px，交互区域至少 44px，不出现横向滚动或文本遮挡。

## 状态与异常

- 服务状态为正常、降级、故障三态，不能只依赖颜色，必须同时显示图标和文字。
- 公共设置未加载时使用现有默认品牌值，不阻塞首页渲染。
- 文档 URL 不可用时隐藏文档入口；用户已登录时主按钮切换为对应控制台路径。
- 客户端时间早于统计起点时，运行时长显示为零，不出现负数。

## 验收标准

- 1440 x 900px 内完整展示品牌、价值主张、两个核心入口、路由场景、服务状态和模型能力，页面无纵向滚动。
- 390 x 844px 视口无横向或纵向滚动、遮挡和溢出。
- 浅色与深色主题使用相同布局，并分别达到 WCAG AA 文本对比度。
- 默认打开页面时必须进入深色主题，显式切换后才显示浅色主题。
- 运行时长在页面加载后立即显示，并以一秒为周期递增。
- 扫描动画必须保持在独立路由区域内，不覆盖文案；扫描束经过节点时不能遮挡节点名称或状态。
- 视觉与现有 Logo、青绿主色和后台产品保持一致，同时明显弱化模板感。
- 普通文本对比度达到 WCAG AA，所有交互元素具备可见焦点状态。
- 效果图由真实浏览器渲染生成，并检查页面无控制台错误、核心资产加载正常。
